전기기능사 CBT 고정 앱 커밋 `b9a682ccff1b460334b78d5bfad9375b7ec4fbb6`의 React·TypeScript·Vite 화면과 학습 로직을 재사용했습니다. 표준은 원본 main `76b990b8720adfa85c22a0a8f699b17094aa357b`의 cbt-site-standard **v1.4.0**이며 폴더 전체를 복사하고 AGENTS.md에 연결했습니다. 기존 작업 저장소에는 README만 있었고 AGENTS.md는 없었습니다. 원본 저장소 및 다른 배포 프로젝트는 수정하지 않았습니다.

## 기능

실전 모의시험·랜덤 풀이, 절대 종료시각 타이머, 답안 수정·새로고침 복원·만료 자동 제출, 과락 채점, 결과·해설·오답 재학습, 북마크·학습 통계, JSON/CSV 로컬 등록·중복 검사·검수 승인·검색·내보내기, 기록 백업·확인 후 초기화가 있습니다. 학습 기준 선택 메뉴와 상단 상시 안내 배너는 없습니다. 두 모드에서 답안 선택 후 Space로 다음 문제로 이동합니다. 마지막 문제에서는 자동 제출하지 않습니다.

모바일 메뉴 전체에 독립 세로 스크롤·100vh/100dvh 제한·항목 높이 보존을 적용했습니다. 기록은 `construction-safety-cbt:v1`에 저장하며 최근 응답 5,000개·시험 30회를 보관합니다. 기본 은행은 초기화해도 유지됩니다. 저장 손상·실패 시 경고하며 손상 원본을 자동 덮어쓰지 않습니다. 백업은 내보내기이며 UI 복원 기능은 없습니다. iframe·시크릿 모드·origin 변경에 따라 저장 접근과 기록이 달라질 수 있습니다.

## 실제 문제은행과 검수 범위

기본 JSON 등록 **1,000개**, ID·정규화 본문/보기 중복 제거 후 **1,000개**. 기출 **0**, 복원 **0**, 자체 제작 **1,000**입니다. 전부 계산 조건 변형이며 **20개 독립 유형 × 50개 조건**, 유형당 최초 조건을 제외한 추가 변형은 **980개**입니다. 과목별 4개 유형·200개입니다. 기출 연도·회차는 모두 null입니다. 이 수는 1,000개 독립 개념이나 균형 잡힌 시험 범위의 확보를 뜻하지 않습니다.

AI 일반 지식의 기초 공식을 사용해 원고를 만들었습니다. 직접 읽지 않은 공식 문헌·교재를 출처로 인용하지 않았습니다. 출처 URL은 작성 코드 위치이며 외부 정답 근거가 아닙니다. 외부 기출의 복제 없이 자체 원고를 CC BY 4.0으로 제공합니다. 원본 앱 코드의 MIT 고지는 LICENSE에 보존했습니다.

20개 템플릿의 식·조건·단위·해설을 내부 검토하고 1,000개 각각을 별도 역산 경로로 검사했습니다. 정답 위치·보기 중복·연도/회차 null·데이터 형식도 검사합니다. `reviewed`는 이 **내부 검수 범위**를 의미합니다. 법령 수치, 현장 적합성, 외부 전문가 검수, 공식 출제기준 대조, 전체 시험의 개념형·법규형 범위 검수는 완료하지 않았습니다. 의미상 동일한 계산 절차는 family로 묶어 그대로 공개했습니다.

시험 추출 시 과목당 먼저 family 4개에서 1개씩 뽑고 나머지 16개는 같은 과목의 미선택 ID로 보충합니다. 유형이 적어 한 시험에 같은 계산 유형이 반복됩니다. 이 문제은행은 계산 연습에 편중되어 실전 대비의 충분성을 보장하지 않습니다. 내부 검수 수량 부족은 0개지만, 공식 기준과 전문가 검수가 완료된 문항은 0개입니다.

## 실행·검증

Node 24.19.0, npm 11.9.0. 기존 lockfile을 유지했습니다.

```sh
npm ci --cache /tmp/cbt-npm-cache --no-audit --no-fund
npm test
npm run build
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npx playwright test
npm run dev
```

브라우저가 없으면 `npx playwright install --with-deps chromium`을 사용합니다. 컨테이너의 npm 기본 캐시 경로가 쓰기 불가여서 /tmp 캐시를 사용했습니다. TLS·무결성 검증은 유지합니다. `python scripts/generate-bank.py`로 데이터·양식을 결정적으로 재생성할 수 있습니다.

검증 결과와 배포 상태는 [검증 기록](docs/validation.md)에 기록합니다.

## 배포 정책

`main` push → validate(단위·빌드·PC/모바일 검사) → GitHub Pages 자동 배포입니다. PR은 검증만 합니다. 이미 push 실행이 있으면 수동 실행을 더하지 않습니다. 사전 권한·인증·네트워크 확인부터 최초 파이프라인까지 첫 차단/실패/승인 필요 시 즉시 중단하고 재실행·대체 배포·배포 유발 추가 push를 하지 않습니다. 사용자 명시 요청이 있어야 새로운 시도가 가능합니다.

예상 주소: https://YunSangYeong.github.io/Engineer-Construction-Safety-CBT/
이 주소 기재 자체는 배포 성공 또는 공개 확인을 의미하지 않습니다.

현재 배포는 Pages API 사전 조회의 프록시 CONNECT 403에서 **중단**했습니다. main push·CI·배포 실행은 하지 않았으며 공개 상태는 미확인입니다. 코드는 자동 배포가 없는 `implementation/construction-safety-cbt` 브랜치로 보존합니다. 사용자 직접 마무리의 첫 단계는 환경 네트워크 허용 도메인에 `api.github.com` 추가입니다. 에이전트는 새 명시적 요청 없이 재시도하지 않습니다.
